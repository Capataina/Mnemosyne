# apps/lynceus/src-tauri/capabilities/

Tauri v2 capability manifests — the IPC permission grants per window. One file: `default.json`, scoped to the `main` window, granting `core:default`, `opener:default`, `core:path:default`, and `dialog:allow-open` (the folder picker; the only dialog permission the app needs). Distinct from macOS entitlements (`../Entitlements.plist`): capabilities gate the webview→Rust IPC surface, the entitlements gate the process against the OS sandbox. A new plugin's commands fail with a permission error until its grant is added here; keep grants minimal — the asset protocol scope lives in `tauri.conf.json`, not here. `$schema` points into `../gen/` (generated; regenerated by Tauri builds).
