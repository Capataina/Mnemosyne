# docs/history/ — frozen records, kept as records

Deliberately historical: files here describe the project at a past moment and are
**never updated to match current code** — that is the folder's contract, not
neglect. Rank 4 in the docs trust hierarchy: correct about its own moment, stale
about today by design. When something here contradicts `architecture/systems/`
or the code, the contradiction is expected and this folder loses.

```
history/
└── code-health-audit/    the 2026-04-26 audit round, 28 findings across five areas (see its CLAUDE.md)
```

New entries arrive only when a completed effort's record is worth freezing
(distilled decisions go to `engineering/decisions/` instead; plan files get
deleted, not archived here).
